庭園の独立保存確認

試験専用の自己マーカーだけを読み書きします。既存の庭園保存・認証・cookie は読みません。Firebase SDK、認証作成、ゲーム通信はありません。

同じ URL を空の試験用 A/B で使います。A で空を確認して A を記入 → B で空を確認して B を記入 → A/B を再読み込みして、それぞれ自身の文字だけが残ることを確認します。B で A が見えた場合や片方だけ一致する場合は停止します。

これは保存分離の確認用です。2人参加、Firebase 認証、接続成功や、試験開始の許可を意味しません。再読み込み後の確認を含む両 profile の結果がそろうまでは独立性は未確認です。
