# wa-awesome

わ〜鯖で俳句やポエムを楽しむためのWebアプリです。

## 機能

- 俳句
- ポエム
- ルーム作成・参加
- 御印（リアクション）
- 音声読み上げ
- エクスポート

## 利用方法

GitHub Pagesで公開しているページを開き、ルームを作成または参加して遊べます。

## 開発・テスト

Node.js 24以上を使用してください。依存関係をインストールした後、通常のユニットテストとFirestore Emulatorを使ったルールテストを実行できます。

```bash
npm ci
npm test
npm run test:rules
```

`npm test` は参加者役割、UIDベースの個人データ、ワードセット関連の純粋関数を検証します。`npm run test:rules` は認証境界と履歴書き込みをFirebase Emulator上で検証します。本番Firestoreへ接続する必要はありません。

## データと運用上の注意

匿名Firebase AuthenticationのUIDを技術的な参加者識別子として使用し、表示名は画面表示用に保持します。新形式のルームでは手札、作品、フレーズ、投票などの個人データをUIDキーで保存し、旧形式ルームでは表示名キーへのフォールバックを維持しています。

ラウンド中に親が操作できなくなった場合は、別のプレイヤーが確認ダイアログから親を引き継ぎます。親引き継ぎはFirestoreトランザクションで競合を処理し、見学者や現在の親自身は引き継げない設計です。
