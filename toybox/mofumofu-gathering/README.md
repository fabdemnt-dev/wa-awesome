# もふもふ大集合！

スマホ縦画面で遊べるブラフ＆心理戦カードゲームです。  
「ひとりであそぶ」は人間1人＋CPU「こはる」「みつき」、「ふたりであそぶ」は同一端末の人間2人＋CPU「こはる」の3人で遊びます。外部ライブラリ・外部画像・外部API・通信機能は使いません。

## 遊び方

8種類の動物カード（各4枚、合計32枚）を使います。

- ねこ
- うさぎ
- くま
- ひよこ
- きつね
- ぺんぎん
- ぱんだ
- しろくま

最初に各プレイヤーへ10枚ずつ配り、余った2枚は山札として置きます。山札は対戦中には使いません。

自分の番では、手札から1枚を裏向きで選び、動物名をひとつ宣言して相手へ渡します。宣言は本当でも、うそでもかまいません。受け取った側は「ほんと？」または「うそ！」を選びます。

宣言と実際のカードが一致するときに「ほんと？」、一致しないときに「うそ！」を選べば判定成功です。

- 判定成功：渡した側が、そのカードを表向きで受け取ります。
- 判定失敗：受け取った側が、そのカードを表向きで受け取ります。
- 同じ動物を4枚受け取ると「もふもふ大集合！」となり脱落します。

脱落者の手札と表向きカードは捨て札へ移動し、その後の手番・判定・渡す相手から除外されます。最後まで残った1人が勝者です。

残り2人のとき、どちらかの手札が0枚になった場合はその時点でゲーム終了です。表向きカードの合計が少ない方が勝者で、同数なら引き分けです。

## CPU

- **こはる**：素直。本当の宣言をしやすい性格です。
- **みつき**：いたずら好き。うその宣言をしやすい性格です。

CPUの判定は完全なランダムではなく、相手がこれまでどのくらい本当の宣言をしていたかを少しだけ参考にします。初心者でも遊びやすいよう、判断の精度には上限があります。

## ファイル

- `index.html` — 画面構造
- `style.css` — パステル調のUI、カード移動・結果演出
- `script.js` — ゲーム進行、判定、CPUロジック
- `README.md` — この説明

## 起動方法

`index.html` をブラウザで直接開くだけで遊べます。GitHub Pagesでもそのまま公開できます。
## ふたりであそぶ

プレイヤーA・プレイヤーB・CPUこはるの3人戦です。人間の手番や人間が判定する前には全画面の交代画面が表示されます。次のプレイヤーへ端末を渡し、「準備できたらタップ」を押すまで手札は表示されません。ルール・カード枚数・判定・4枚集合による脱落はひとり用と同じです。
